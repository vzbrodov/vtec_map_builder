# vtec_map_builder

Построение карт VTEC по выходам TayAbsTec: значения VTEC на станциях аппроксимируются
вещественными сферическими гармониками, коэффициенты находятся МНК, затем модель
вычисляется на регулярной широтно-долготной сетке.

## Сборка и запуск

```bash
make
./build_vtec_maps 2023 station_coordinates_from_tec.csv output 320 2023 16 2.5 2.5 5e-2 0
```

Аргументы программы:

```text
1 data_dir      папка с данными, например 2023
2 coords_file   CSV с координатами станций
3 output_dir    папка для результатов
4 doy           день года
5 year          год
6 lmax          максимальная степень сферических гармоник
7 lat_step      шаг сетки по широте, градусы
8 lon_step      шаг сетки по долготе, градусы
9 ridge         сглаживающая регуляризация: штраф растет как [l(l+1)]^2
10 weight_radius_deg  радиус плотностных весов; 0 отключает их и оставляет все станции с одинаковым весом
```

Если аргументы не заданы, используются значения по умолчанию:
`2023 station_coordinates_from_tec.csv output 320 2023 6 5 5 1e-8 0`.

Практичный сглаженный вариант для текущего набора данных:
`lmax=16`, шаг сетки `2.5 x 2.5` градуса, `ridge=5e-2`,
`weight_radius_deg=0`. Это использует все станции без плотностного
перевзвешивания и подавляет нефизические высокочастотные осцилляции.

Если нужна более контрастная карта с максимумами ближе к 80-90 TECU:
`lmax=16`, шаг сетки `2.5 x 2.5` градуса, `ridge=1e-2`,
`weight_radius_deg=0`. Этот вариант лучше передает пики, но может давать
отрицательные значения в областях слабого покрытия.

Основные результаты:

- `output/coefficients.csv` - коэффициенты разложения для каждой эпохи UT.
- `output/vtec_grid.csv` - карта VTEC на регулярной сетке.
- `output/fit_diagnostics.csv` - число наблюдений и RMS невязки по эпохам.

## Визуализация

```bash
python3 scripts/plot_vtec_maps.py --grid output/vtec_grid.csv --out-dir output/figures --time 12 --animate
```

Скрипт использует `cartopy`, если он установлен. Если нет, строит обычную карту в
координатах longitude/latitude средствами `matplotlib`.

## Структура Fortran-кода

- `src/my_prec.f90` - точность вычислений, менять `mp` можно здесь.
- `src/spherical_harmonics_mod.f90` - вещественный базис сферических гармоник.
- `src/least_squares_mod.f90` - МНК/взвешенный МНК через нормальные уравнения.
- `src/data_io_mod.f90` - чтение TayAbsTec и запись CSV.
- `src/vtec_model_mod.f90` - аппроксимация по эпохам и расчет карты на сетке.
- `src/main.f90` - только сценарий верхнего уровня.
